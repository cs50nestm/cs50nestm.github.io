Part 1

AI decides by measuring things

AI is a program that makes a decision that usually takes human judgment. Your email app’s spam filter is one example. It can’t read an email the way you do. It can only measure things about it. Each thing it measures is called a feature.

Links

How many links are in the email?

int links

ALL CAPS

How many words are in ALL CAPS?

int caps

Known sender

Do you know who sent it? 1 = yes, 0 = no.

int known

The rule turns features into a score

Each feature gets a weight: how much it counts. Links and ALL CAPS push the score up. Knowing the sender pulls it down. If the score is greater than the threshold, the email is spam.

score = 3 × links + 2 × caps − 5 × known
SPAM if score > 6

The code: spam.c

In class we wrote this in C. The whole “intelligence” is one calculation and one comparison.

#include <cs50.h>
#include <stdio.h>

int main(void)
{
    int links = get_int("Number of links: ");
    int caps = get_int("Words in ALL CAPS: ");
    int known = get_int("Do you know the sender? (1 = yes, 0 = no): ");

    int score = 3 * links + 2 * caps - 5 * known;

    if (score > 6)
    {
        printf("SPAM\n");
    }
    else
    {
        printf("Not spam\n");
    }
}

To run it on cs50.dev: save the file, type make spam, then ./spam.

Try it yourself

Before you move a slider, pick one WRONG email and write down:

  1. Which number you will change, and whether it goes up or down.
  2. Why that change should fix this email. (Is it a missed spam or a false alarm? Which features does it have?)
  3. What you predict its new score will be.

Then move the slider and check. Was your prediction right? Did anything else break? Keep your notes: you can use this change for the Graded Warm-Up.

The strategy: fix one wrong email at a time

Changing numbers at random is just guessing. Instead, pick one WRONG email and ask two questions.

  1. What kind of mistake?

    Missed spam: its score must go up, or the threshold must go down. False alarm: its score must go down, or the threshold must go up.

  2. What does the email have?

    Only weights for features the email actually has can change its score. A weight times 0 is still 0.

Why can’t anyone get 9?

Look at emails 7 and 10. They have exactly the same features, so every rule gives them exactly the same score. But one is spam and one isn’t, so any rule gets one of them wrong.

7. Friend’s hacked account

links 1 · caps 0 · known 1

Answer: Spam

10. Coach’s game schedule

links 1 · caps 0 · known 1

Answer: Not spam

The best possible is 8 out of 10. That limit comes from what the rule can measure, not from how hard you try.

What this says about training AI

No AI is perfect

Real AI systems have error rates too. Some mistakes can’t be tuned away.

It only knows what it measures

Same features, same score. Better features help more than better tuning.

Every rule chooses its mistakes

To get 8, your rule had to get two emails wrong. A school email in spam and a scam in your inbox aren’t equally bad. People decide which mistakes are acceptable.

Humans stay in the loop

Some cases, like a hacked friend’s account, need your judgment.

Training an AI isn’t finding a perfect rule. It’s choosing what to measure, and deciding which mistakes you can live with.
