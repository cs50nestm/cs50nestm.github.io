What C can this stepper run?
  • Variables: int, float, double, long, char, bool, string
  • Loops: for, while, do … while, nested as deep as you like, plus break and continue
  • Decisions: if, else if, else, and &&, ||, !
  • Math and updates: + - * / %, ++, --, +=, -=, *=, casts like (float)
  • printf with %i, %d, %c, %s, %f, %.2f, and widths like %3i
  • get_int, get_float, get_char, get_string (from the Input box), and functions you write yourself
  • Not yet: arrays, pointers, switch, and structs. The stepper stops after 5,000 steps in case a loop never ends.
