// Scratch to C

In Scratch you snapped blocks together. In C you type source code, and a program called a compiler translates it into the 0s and 1s (machine code) that the computer actually runs.

Source code

#include <stdio.h>

int main(void)
{
    printf("hello, world\n");
}

What humans write and read. Saved in hello.c.

→make hello

Compiler

make hello
(runs clang for you)

Checks your syntax and translates. Errors? Fix the first one first.

→./hello

Machine code

01111111 01000101
01001100 01000110
00000010 00000001
...

What the CPU runs. Binary, just like Unit 0.

Correctness

Does the program do what it is supposed to? check50 tests this.

Design

Is it written well? No repeated code, no wasted steps.

Style

Is it easy to read? Indentation, clear names, comments. style50 helps.

// Key Concepts

Every idea from Scratch has a C version. Same thinking, new syntax.

Functions say block

A function does a job. Some take arguments (input). Some give back a return value (output).

printf("hello, world\n");
string name = get_string("Name? ");

\n is an escape sequence that means "new line."

Variables set block

A named box that holds a value. In C you must say its type first. = means "gets," not "equals."

int counter = 0;
counter = counter + 1;
counter += 1;
counter++;   // all three add 1

Format codes placeholders

printf fills each placeholder with the next value, in order.

string name = "Ada";
int age = 17;
printf("%s is %i\n", name, age);
// Ada is 17

Operators math

+ - * / and % (remainder). Dividing two ints throws away the decimal.

printf("%i\n", 7 / 2);    // 3
printf("%i\n", 7 % 2);    // 1
printf("%f\n", 7 / 2.0);  // 3.500000

Conditionals if / else

Choose a path with a Boolean expression (true or false). Compare with ==. Combine with && (and), || (or).

if (x < y)
{
    printf("x is less than y\n");
}
else if (x > y)
{
    printf("x is greater than y\n");
}
else
{
    printf("x is equal to y\n");
}
if (x = 5) assigns 5 to x. To compare, write if (x == 5).

Loops repeat / forever

for when you know how many times. while while something is true. do while runs at least once, which is perfect for asking the user again.

for (int i = 0; i < 3; i++)
{
    printf("meow\n");
}

int n;
do
{
    n = get_int("Size: ");
}
while (n < 1);

Comments & pseudocode

Plan first in plain English, then turn each line into a comment and fill in the code under it.

// Prompt user for positive integer
// Print that many bricks

Constants & magic numbers

A number dropped into code with no explanation is a magic number. Name it with const so readers know what it means and it cannot change.

const int MAX_HEIGHT = 8;

// Data Types

The type tells C how much memory a variable needs and how to read its bits. Each type pairs with a format code for printf. The CS50 library adds get_int, get_float, get_string and friends.

TypeHoldsFormatExample
intWhole numbers (about ±2 billion)%iint score = 95;
longBigger whole numbers%lilong card = 4003600000000014;
floatNumbers with a decimal point%ffloat price = 2.50;
doubleDecimals with more precision%fdouble pi = 3.14159265;
charA single character, in single quotes%cchar answer = 'y';
stringText, in double quotes (CS50 library)%sstring name = "Ada";
booltrue or falsenonebool done = false;

// Limits of Computers

    
Computers store numbers in a fixed number of bits. That causes two famous problems.

    

      

        
Integer overflow

        
With only 8 bits, the biggest number is 255. Add 1 and it wraps back to 0, like a car odometer. An int has 32 bits, so it overflows past 2,147,483,647.

        

        
250

        

          
          
        

      

      

        
Floating-point imprecision

        
Some decimals, like 0.1, cannot be stored exactly in binary. Print enough digits and the error shows up.
