Inside arrays

Essential Question

How does a computer store and organize many pieces of data at once?

Learning Goal

I can use arrays and strings to store data and loop through them to solve problems.

cs50.dev · terminal
$ make caesar
$ ./caesar 1
plaintext:  HELLO
ciphertext: IFMMP
$

// Compiling, Up Close

In Unit 1, make felt like one step. It is really four. When you type make hello, the compiler clang runs all four for you.

Step 1

Preprocessing

#include <cs50.h>
// becomes
string get_string(
  string prompt);

Each #include line is replaced with the function prototypes from that header file.

Step 2

Compiling

main:
  pushq %rbp
  movq  %rsp, %rbp
  ...

C is translated into assembly code, simple instructions for the CPU.

Step 3

Assembling

01111111 01000101
01001100 01000110
...

Assembly is turned into machine code: the 0s and 1s.

Step 4

Linking

hello.c  + cs50.c
+ stdio.c → hello

Your machine code is combined with the library code you used into one program.

make vs. clang

make hello runs something like clang -o hello hello.c -lcs50 for you.

Header files

Files ending in .h list what a library can do, so the compiler knows the functions exist.

-lcs50

Tells the linker to link in the CS50 library's code, like get_string.

// Debugging

A bug is a mistake in your code. Debugging is the detective work of finding it. Use these three tools, in this order.

printf look inside

Temporarily print the values of variables to see what your program is really doing. Delete these lines when you're done.

printf("i is %i\n", i);

debug50 step through

Click left of a line number to set a red breakpoint, then run:

debug50 ./buggy

Step over runs one line. Step into goes inside a function you wrote. Watch variables change on the left.

Rubber duck talk it out

Explain your code, line by line, out loud to a rubber duck (or to cs50.ai). You often hear the bug as you say it.

You seeIt usually means
expected ';'You forgot a semicolon at the end of the line above.
use of undeclared identifierA variable is misspelled, never declared, or used outside its scope (outside its curly braces).
call to undeclared functionMissing #include, or your function is defined below main with no prototype above it.
Segmentation faultYour program touched memory it should not, often an array index that is too big.

Tip: fix the first error first. One mistake can cause many messages below it.

// Key Concepts

An array stores many values of the same type, back to back in memory. A string is just an array of characters.

Arrays a list of boxes

Give the type, a name, and how many. Count from 0, so the last index is one less than the size.

int scores[3];
scores[0] = 72;
scores[1] = 73;
scores[2] = 33;

int scores[] = {72, 73, 33};  // same thing

Looping over arrays

A for loop's i is the perfect index. This replaces three copies of the same code.

const int N = 3;
int sum = 0;
for (int i = 0; i < N; i++)
{
    sum += scores[i];
}
C does not check your index. scores[3] reads past the end of the array and may crash.

Strings arrays of chars

A string is a sequence of chars. Use square brackets to get one character.

string s = "HI!";
printf("%c\n", s[0]);   // H
printf("%c\n", s[2]);   // !

The NUL character \0

Every string ends with a hidden '\0' (all zero bits) so the computer knows where it stops. "HI!" takes 4 bytes, not 3.

// H   I   !   \0
// 72  73  33  0

String length strlen

strlen counts characters until '\0'. Save it in n so it is not recalculated every time through the loop.

for (int i = 0, n = strlen(s); i < n; i++)
{
    printf("%c", s[i]);
}

Chars are numbers ASCII

Every char is stored as its ASCII number, so you can do math with letters. Lowercase is 32 more than uppercase.

printf("%i\n", 'A');       // 65
printf("%c\n", 'A' + 1);   // B
printf("%i\n", 'C' - 'A'); // 2

Your own functions

Put a prototype above main so the compiler knows the function exists. Parameters go in, a return value comes out.

int square(int n);   // prototype

int main(void)
{
    printf("%i\n", square(5));
}

int square(int n)
{
    return n * n;
}

Scope where it lives

A variable only exists inside the curly braces where it was created. Need it later? Declare it before the braces.

for (int i = 0; i < 3; i++)
{
    ...
}
printf("%i\n", i);  // error!

Command-line arguments

Words typed after the program name are passed to main. argc counts them, argv is an array holding them.

int main(int argc, string argv[])

Exit status

main returns 0 when all went well. Return a non-zero number to signal an error.

if (argc != 2)
{
    printf("Usage: ./caesar key\n");
    return 1;
}

// Libraries

Each header file unlocks a set of functions. Look any of them up at man.cs50.io.

FunctionHeaderWhat it doesExample
get_stringcs50.hAsk the user for textget_string("Text: ")
printfstdio.hPrint formatted outputprintf("%c", c)
strlenstring.hNumber of characters in a stringstrlen("CS50") is 4
isalphactype.hIs it a letter?isalpha('b') is true
isdigitctype.hIs it a digit 0 to 9?isdigit('7') is true
isupper / islowerctype.hIs it uppercase / lowercase?isupper('Q') is true
isspace / ispunctctype.hIs it a space / punctuation?ispunct('!') is true
toupper / tolowerctype.hChange case (non-letters stay the same)toupper('b') is 'B'
atoistdlib.hTurn a string of digits into an intatoi("13") is 13

Tip: the is functions return a non-zero number for true and 0 for false, so use them right inside an if.

// String Lab

Type any string and see how it sits in memory: one char per box, an index above, its ASCII number below, and the '\0' at the end.

Notice: 'A' is 65 and 'a' is 97, a difference of 32. A space is 32, and the digit '0' is 48, not 0.

// Cipher Lab
